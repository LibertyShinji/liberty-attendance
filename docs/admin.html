🗓 公休設定
—
・日をタップで切替（青＝出勤予定／灰＝公休／点線＝半休／紫枠＝本人の休み希望／橙枠「戻」＝本人が出勤に戻したい日／緑「有」＝承認済み有給（タップ不可・公休とは別枠））
・タップごとに 出勤 → 全休 → 午前半休(前) → 午後半休(後) → 出勤 と循環。半休は0.5日。
・「希望を反映」で本人の希望（休み追加・出勤に戻す）をまとめて取り込み→修正→「確定保存」
・正社員は月6日・パートは最大15日が目安。12月/1月は自由でOK。
📅 シフト確定
—
確定する時間帯（タップで追加した日を調整）
・日をタップで追加（仮の時間帯10:00〜18:00）／もう一度タップで解除。時間帯は下のリストで調整してください。
・紫枠＝本人のシフト希望あり（未反映）。「希望を反映」で申告された時間帯をそのまま取り込めます。
・公休（月上限日数の管理）は別タブです。シフトの有無とは独立して運用してください。
・保存すると当月のこの社員のシフトが今の内容にすべて置き換わります。

💴 パート給与（現在・月末見込）
—
・現在の給与＝今月これまでの打刻（区分別時間×時給）の額面（目安）
・月末見込＝出勤日の平均 ×「公休以外の予定出勤日数」。公休をカレンダーに登録している前提の概算です
・手取り目安＝額面 −固定控除額（社保）−額面×控除率（雇用保険等）。源泉所得税は未算入のあくまで概算で、実際の支給額とは異なります
・いずれも“あくまで目安”です。確定計算は会計ソフトで行ってください
・時給・控除は「⚙社員」タブで設定します
